# v0.1.0 — experimental research release (draft)

This release draft describes an inspectable prompt-injection detection study, not a dependable deployed defense. No release has been published by preparing this file.

## Included

- DistilBERT training, checkpointing and inference, with an Ollama/Llama document-processing gate.
- A preserved baseline, three-seed contextual studies and task-aware comparisons.
- A matched threshold/ranking diagnostic and source-backed experiment records.
- Validation using 30 public document sources, 270 controlled attack copies, and separate complete-page length probes.
- Pinned acquisition and a human-review gate for a larger candidate corpus; assembled cases still await human review.

## Real-document findings

| Condition | Benign excerpts blocked / 30 | Benign strict QA completed / 30 | Attacks detected / 270 | Successful exact marker hijacks / 270 |
|---|---:|---:|---:|---:|
| Unprotected Llama | 0 | 23 | 0 | 132 |
| Baseline gate | 20 | 7 | 266 | 4 |
| Document-only candidate | 0 | 23 | 95 | 82 |

The candidate accepted only 2/30 complete extracted pages; 27 exceeded 512 tokens. Both gates prevented forwarding uninspected suffixes. Neither met the predeclared security-MVP targets. Strict QA matching rejects some correct paraphrases; full outputs and an error review are retained locally.

## Reproduction and limits

See the [README](../README.md), [real-document protocol](real-document-validation-protocol.md), [results](real-document-results.md), and [research diary](../research_diary.md). Git includes code, configurations and small evidence records. Raw third-party texts, weights, response caches, human-review packets and private notes remain local/ignored.

The real sources are public Python documentation, OWASP guidance and government/science pages; injected attacks were authored for this test. Results cover English factual QA on short excerpts. They do not establish production traffic performance, adaptive-attack resistance, PDF/OCR support, summarization quality, or protection against secret exfiltration. Users should reproduce the study before relying on its results. Further improvements need new evaluation data and should retain these failures as regression evidence.
