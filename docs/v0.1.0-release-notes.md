# v0.1.0 — experimental release draft

**Status:** research-release draft. Security/utility evidence does not support a dependable-defense claim.

## Included work

DistilBERT training controls and loss ablations; local Llama gating; source/threshold diagnostics; public-document validation; frozen data/checkpoint provenance; offline gradient, accumulation and resume tests. Raw corpora, weights, optimizer state and response logs remain local.

## Measured limitations

[Public-document validation](real-document-report.md) failed security/utility targets; 27/30 complete pages exceeded the detector context. [Consistency training](context-consistency-report.md) improved recall to 68.1% but retained 11.9% benign false alarms on constructed cases. The evidence does not establish arbitrary-document, adaptive-attack or exfiltration protection.
